Применяй правила инженерной работы из файла ниже в рамках текущего поручения и инструкций проекта.

@gigacode-workbench/SYSTEM_PROMPT.md

Для задач, выполняемых через Workbench, также прочитай `gigacode-workbench/BOOTSTRAP.md`. Актуальная цель — GigaCode CLI 26.10.6; при настройке сначала прочитай реальную версию выбранного executable и его справку. Исторические сведения 26.9.75 не подтверждают новый runtime.

Для порученной самонастройки начни с `gigacode-workbench/START-HERE.md`. После неё используй сохранённую карточку продолжения по `gigacode-workbench/docs/POST_SETUP_HANDOFF.md`: предложи GigaCode UI, а при уже принятой задаче восстанови текущий шаг. При другом поручении или отложенном UI не перенаправляй работу. Если этот блок используется вне проектной папки пакета, агент при подготовке контекста заранее заменяет пути фактическими абсолютными значениями; установщик сам не подставляет пути в подготовленный глобальный GIGACODE.md.
