Для задач, выполняемых через Workbench, также прочитай `gigacode-workbench/BOOTSTRAP.md`.

После неё используй сохранённую карточку продолжения по `gigacode-workbench/docs/POST_SETUP_HANDOFF.md`: предложи GigaCode UI, а при уже принятой задаче восстанови текущий шаг. При другом поручении или отложенном UI не перенаправляй работу. Если этот блок используется вне проектной папки пакета, агент при подготовке контекста заранее заменяет пути фактическими абсолютными значениями; установщик сам не подставляет пути в подготовленный глобальный GIGACODE.md.
