# Настройка новых проектов

Этот сценарий универсальный и запускается только по явному запросу создать или настроить новый проект. Существующие проекты пользователя уже настроены. Первый запрос в таком репозитории не запускает переустановку, генерацию всей документации, настройку hooks или переписывание GIGACODE.md.

## Обычная работа в существующем проекте

Прочитать относящиеся к задаче инструкции, установить рабочую копию и необходимые команды. Использовать действующие MCP и доступы. Отсутствие config файлов Workbench допустимо: контекст можно сохранить в задаче. Если реальная нехватка настройки блокирует работу, сообщить конкретную причину и предложить минимальное исправление; не запускать общее переустройство.

## Новый проект

1. Установить назначение, стек, runtime, платформы и ограничения по запросу. Ничего не наследовать от названий личных проектов пользователя.
2. Выбрать минимальную структуру и необходимые проверки. Использовать подтверждённые версии и команды; не создавать пустые шаблоны бизнес-функций под видом реализации.
3. Зафиксировать краткий проектный контекст: назначение, команды, точки входа, правила изменений, источники документации. Большие каталоги файлов хранить отдельно и загружать по запросу.
4. Создать только необходимые конфигурации. Секреты остаются в предназначенном для них хранилище; в файлах — имена переменных и порядок получения доступа. Git hooks и CI добавлять, если это входит в поручение; не заменять существующие hooks автоматически.
5. Выполнить минимальные сборку/запуск/проверку, соответствующие типу проекта, и сохранить фактические результаты. Неприменимость проверки объяснить.
6. Передать краткую памятку и известные ограничения. Дальнейшие задачи используют обычные quick/standard/deep маршруты, а не повторяют настройку.

Маршрут в каталоге — `onboarding`; его activation имеет значение `explicit-new-project-only`. Это прикладное условие выбора host, не встроенная функция GigaCode. Технические конфигурации-примеры в config/ остаются неактивными до заполнения проверенными данными.
