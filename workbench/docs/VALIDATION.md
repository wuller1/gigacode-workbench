# Проверка текстового пакета

## Обновление 1.2.0 — 10 октября 2026 года

- Пакет: 218 файлов разрешённых форматов `.md`, `.txt`, `.json`, `.svg`, `.png`; 52 графических файла, в том числе 34 собственные SVG-иконки, atlas SVG/PNG и 16 снимков макета. Готовых исполняемых файлов и executable bits нет. Текстовые исходники — 12/12 с прежними hashes.
- Проверены UTF-8/JSON, локальные ссылки, безопасная статичная структура SVG, PNG, отсутствие внешних image embeds, manifest и содержимое ZIP по hashes. Это проверка поставки, не работоспособности будущего Electron-кода.
- ZIP распакован в отдельную временную область. Подготовка исходников, план/установка, installed validate и повтор/no-op прошли. Сверены все **240 installed hashes**, **52 графических файла побайтно**; каталог содержит **9 профилей, 29 workflows, 143 этапа**. Глобальная среда не менялась. Установленная команда ссылается на существующие абсолютные startup/handoff paths; пример handoff не выдаётся за действующую карточку или авторизацию.
- Runtime установки: **PowerShell 7.4.20 на macOS arm64**. Windows PowerShell 5.1 и GigaCode 26.9.75 на рабочем компьютере не запускались. Статическая совместимость и прежние проверки неизменённых скриптов приведены ниже.
- Согласованы **43 группы требований**, **38 групп UI/сервисов**, карточки M0–M12 и поставки D0–D13. Последний независимый проход уточнил роль analyst как автора описания/SDD, queued-only archive без фиктивного запуска и локальный resource hold.
- В браузерном макете реально проверены: свободный ответ после сворачивания, поиск/восстановление archived Task в навигацию, выбор/наследование/отмена settings, сохранение custom profile draft, фильтр файлов, очередь, Markdown-таблица/код, статусы плана/исполнителей; browser tab rename через меню/double-click/F2, закрытие отдельной вкладки, смена ориентации и разворот с возвратом по Escape. Полная ширина развёрнутого preview измерена: panel 1246 px при workspace 1246 px. На 320 px root/scrollWidth совпали — 288/288 для чата и настроек. Runtime-ошибок JavaScript в проверенных действиях не обнаружено.

Live CLI/ACP, настоящие PTY/browser navigation и screenshots, применение reasoning в GigaCode, эмуляция DPR, внешний браузер и OS fullscreen, долговечная база/полное восстановление здесь **не проверены**. Переименование/переходы в макете — локальные fixtures. Повторные поведенческие наборы неизменённых PowerShell-источников без новой причины не запускались. Снимки и актуальные границы — [UI_PREVIEW_GUIDE](UI_PREVIEW_GUIDE.md), [ITERATION_AUDIT](ITERATION_AUDIT.md).

Реальное выполнение: **PowerShell 7.4.20 на macOS arm64**, локальные Git и Node. Windows PowerShell 5.1 отсутствует в этой среде: статический анализ не заменяет runtime-проверку. Анализ языка/команд/типов не доказывает поведение Windows filesystem, антивируса или корпоративной execution policy. Пакет не обходит ограничения и не устанавливает PowerShell 7 на рабочую машину.

В 1.1.1 изменены входные инструкции и передача контекста после настройки, а 12 PowerShell-источников остались побайтно прежними. Автоматическое следование этим инструкциям моделью GigaCode и обнаружение карточки после реального перезапуска здесь не проверялись; POST_SETUP_HANDOFF задаёт адресный recovery probe на целевом компьютере. Проверка ZIP/установщика не заменяет этот сценарий.

## Что ещё требует целевой проверки

- Windows PowerShell 5.1 FullLanguage, Add-Type, атомарные записи, подготовка/установка и тесты на рабочей Windows.
- Загрузка system prompt, native command/agents, модели, image input и разрешения именно в GigaCode 26.9.75.
- Реальные MCP Git/Jenkins/OpenShift/Confluence/Sprut и операции; Sprut проверяет уязвимые версии библиотек по описанию пользователя, имена tools ещё нужно обнаружить.
- Параллельные чаты, cancel, restore и 429 в настоящем пользовательском Electron UI и CLI. Qwen snapshot и локальная fixture не устанавливают причину конкретного сбоя.
- DOM измерения и качество настоящих экранов. Node tests проверяют функции, а не браузерную геометрию и не полное соответствие WCAG.
- Работа промптов на пользовательских aliases DeepSeek/MiMo/GLM; характеристики и качество по названиям не придуманы.
- Скорость старой/новой обвязки на одинаковых задачах. Сокращение обязательных действий не объявляется измеренным ускорением.
- Нативная интеграция и новая UI-функциональность из плана. В пакете находятся инструкции и reference controller; пользовательский UI здесь не модифицирован.

Zidao и Qwen исследовались по исходникам. Версии и источники Zidao сохранены в документах аудита; проект не изменён, новые UI/продуктовые метрики не получены. Источники open source закреплены по commits и LICENSE; зависимости не установлены в проект пользователя.

## Повторение на целевой машине

Из каталога распакованного пакета, после проверки правил среды:

```powershell
Copy-Item -LiteralPath .\source\prepare-scripts.txt -Destination .\prepare-scripts.ps1
powershell -NoProfile -File .\prepare-scripts.ps1
powershell -NoProfile -File .\workbench.ps1 validate
powershell -NoProfile -File .\tests\run-tests.ps1
```

Если prepare-scripts.ps1 уже существует, сначала сверить его с source/prepare-scripts.txt, не перезаписывать отличающийся пользовательский файл. Для обязательных восьми Node checks при установленном Node добавить `-RequireNode` к test runner. Без Node они явно получают not_run, не pass. Python для работы и повторения основных проверок не требуется.

Почтовая поставка содержит UTF-8 `.md`, `.json`, `.txt` и разрешённую пользователем графику `.svg`/`.png`: 29 собственных иконок и общий лист просмотра. Готовых `.ps1`, `.py`, `.js`, библиотек, исполняемых файлов, вложенных архивов и runtime нет. SVG проверяются как статичная геометрия без script, событий, ссылок и внешних загрузок; PNG — реальное растровое изображение. Текстовые источники превращаются в рабочие файлы только на целевой машине. `scripts.json` содержит 12 точных пар source/target и SHA-256, `MANIFEST.txt` — hashes всего комплекта кроме самого manifest. Они обнаруживают изменение байтов, но не являются цифровой подписью издателя.

Успех проверок относится к перечисленным свойствам и версиям. Он не подтверждает всю семантику отчёта модели и не гарантирует отсутствие всех регрессий.

## Макет интерфейса вне почтового пакета

Интерактивный демонстрационный макет проверен отдельно в браузере: переключение задач сохраняет черновик и демонстрационное состояние; автоматически выбранная следующая роль откладывается до idle и показывается read-only; model selector и неизвестный context отображаются; правый rail открывает инструменты; две terminal tabs и две browser tabs выбираются независимо. На ширине 320 px контролы не выходили за границы, JavaScript errors в проверенных шагах не обнаружены. Ранее проверено боковое размещение без пересечения с центральной областью. Это демонстрация, процессы терминала/CLI и браузерные сессии в ней не запускаются. Native drag через управляющий инструмент не подтвердил перенос; полноценные drag/tab-group/OS-взаимодействия остаются обязательной live-приёмкой M3. Статус этого сценария не записан как pass.
