# Локальный встроенный CLI

Эта папка в публичном репозитории содержит только инструкцию. Собственный GigaCode CLI добавляется локально перед сборкой, если у вас есть готовый самостоятельный комплект и право на такое использование.

Из каталога `app`:

```text
node tools/bundle-cli.mjs --source "C:\BuildInputs\GigaCode-runtime" --entry "bin\gigacode.js"
```

Для готового самостоятельного Windows executable укажите его относительный `.exe` путь. Поддерживаются также `.mjs` и `.cjs`. Исходный каталог должен содержать все необходимые зависимости; помощник ничего не устанавливает и не запускает.

Результат — `package/` с неизменёнными байтами и `runtime.json` с адресом entrypoint и его SHA-256. Уже существующий комплект заменяется только с `--replace`. Исходный каталог не меняется. Этот README сохраняется при замене.

`package/` и `runtime.json` — локальные входы сборки, а не содержимое публичного Git-репозитория. Не переносите `.env`, пользовательскую авторизацию, историю сессий, cookies, ключи или весь каталог профиля GigaCode Desktop. Проверка известных имён файлов не является полным сканированием секретов внутри произвольных бинарников/архивов.

Подробности, ограничения и проверка уже собранного приложения: [BUNDLED_CLI.md](../../docs/BUNDLED_CLI.md).
