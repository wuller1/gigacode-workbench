# Application icon

The GigaCode Workbench icon is an original project asset. It was drawn specifically for this repository and does not reuse third-party logos, icons, screenshots, or other copyrighted artwork.

The woven `W` represents parallel work sessions converging into one coordinated result. The compact title-bar marks use the same geometry.

- `icon.svg`, `icon.png`, and `icon.ico` are the default packaging assets.
- `icon-light.svg` and `icon-light.png` are the light-theme presentation variant.
- `icon-dark.svg` and `icon-dark.png` are the dark-theme presentation variant.
- `../public/icons/brand-light.svg` and `brand-dark.svg` are the in-app title-bar assets.

Keep the geometry consistent across variants. Theme adaptations may change the background, contrast, and ribbon colors while preserving the silhouette.
