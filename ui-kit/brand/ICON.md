# Workbench mark

The original mark combines a horizontal work surface, two stable legs and a central `W` brace. The bench silhouette keeps it from reading as a generic lowercase `w` or omega at display size. It was drawn for this starter without tracing or importing a vendor, competitor or Sber asset.

- `workbench-mark.svg` and `workbench-mark-inverse.svg`: scalable 64-unit presentation sources.
- `workbench-mark-24.svg` and `workbench-mark-24-inverse.svg`: optically simplified 16–24 px title-bar sources.
- `workbench-app-icon.svg`: 512-unit rounded application-icon source and prototype preview.

Use the mark unboxed in app chrome at 16–18 px. Use `semantic.text.primary` on light/dark shell surfaces. Do not add a bright badge, gradient, glow, wordmark collision or animation. The application icon uses `semantic.action.primary`-family dark green with `semantic.action.on-primary`; platform exports must be generated from the approved source and checked at 16, 20, 24, 32, 48, 256 and 512 px.

This mark is awaiting user and organization brand/trademark approval. It is intentionally not wired into `app/build` or `app/public`; those production assets change only after explicit approval of the prototype revision.
